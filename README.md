# 袅来运转网页版 v1.5.6

这是用于 GitHub Pages 的静态网页发布文件。线上地址：[袅来运转网页小工具](https://miatheamateur.github.io/niaolaiyunzhuan-web/)；线上版本以实际部署为准。

将包内文件上传至仓库根目录，确保 `index.html` 与 `app.js`、`data.js` 位于同一层级。GitHub Pages 选择 `main` 分支、`/(root)` 文件夹。

数据来自飞书正式维护表修订 772，包含 132 条有效来源、213 个独立目标。V1.5.6 新增限时活动“11.5故障补偿”10 颗，作为 1 个独立目标向老用户显示 1 个 NEW；既有勾选记录继续保留。跨端可使用“记录保护”PNG 备份图合并恢复。
