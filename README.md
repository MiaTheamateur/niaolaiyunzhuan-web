# 袅来运转网页版 V1.6.2

这是用于 GitHub Pages 的静态网页发布文件。线上版本以实际部署为准。[打开袅来运转网页小工具](https://miatheamateur.github.io/niaolaiyunzhuan-web/)

将包内文件上传至仓库根目录，确保 `index.html` 与 `app.js`、`data.js` 位于同一层级。GitHub Pages 选择 `main` 分支、`/(root)` 文件夹。

数据来自维护表修订 814，共 137 条有效来源、232 个独立目标。新增“11.5回档补偿”10 颗，作为 1 个勾选目标向老用户显示 1 个 NEW。“空中楼阁宝箱”更名为“芙蕖苑桥下宝箱”，获取提示同步补充坐车路线。

旧整组勾选和旧备份会迁移到原有各颗。逐颗备份使用 NYNZ3 格式，支持恢复 NYNZ1、NYNZ2 旧图，新图需使用 V1.6.0 或后续兼容版本读取。
